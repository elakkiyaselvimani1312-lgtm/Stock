Stock Price Prediction 📈

A simple Stock Price Prediction project developed using Python.
This project uses historical stock data to predict future prices using Machine Learning.

📌 Features
Load stock market dataset
Analyze stock price trends
Train prediction model
Predict future stock prices
Display graph using matplotlib
🛠️ Technologies Used
Python 3
Pandas
NumPy
Matplotlib
Scikit-learn
▶️ How to Run
Install Python on your system.
Install required libraries:
pip install pandas numpy matplotlib scikit-learn
Run the program:
python taskt.py
